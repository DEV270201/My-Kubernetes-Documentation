# ☸️ Kubernetes Learning Journal

> A day-by-day journal of my Kubernetes learning journey — from absolute zero to hands-on experimentation.

I started with no prior Kubernetes experience and documented everything I explored, understood, and experimented with along the way. This repo is not just personal notes; it is meant to be a beginner-friendly resource for anyone learning Kubernetes. Each day covers the concepts I learned, the commands I ran, the experiments I performed, and the gotchas and errors I ran into and how I resolved them.

Learning from real mistakes is often more valuable than reading polished docs alone.

If you are just getting started, follow along day by day. If you are looking for something specific, jump to whichever day covers that topic.
