# Kubernetes Learning Journal

This is a day-by-day journal of my Kubernetes learning journey. I started from scratch with no prior Kubernetes experience and documented everything I explored, understood, and experimented with along the way.

The goal of this repo is not just to be my personal notes but to serve as a beginner-friendly resource for anyone who is also learning Kubernetes. Each day's entry covers the concepts I learned, the commands I ran, the experiments I performed, and importantly, the gotchas and errors I ran into and how I resolved them. Learning from real mistakes is often more valuable than reading polished docs alone.

If you are just getting started with Kubernetes, you can follow along day by day. If you are looking for something specific, jump to whichever day covers that topic.
